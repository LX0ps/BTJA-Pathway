# BTJA-Pathway
Notes, lab write-ups, and practical exercises from the Centri Blue Team Junior Analyst pathway
Centri is a platform dedicated to cybersecurity education. They offer a range of free courses with certificates in areas such as digital forensics, network analysis, threat hunting, and more. 

**About This Repository**

This repository is for the challenges included in the __BTJA Pathway Certificate__ offered by Centri. The six courses include:
- Dark Web Operations
- Network Analysis
- OSINT
- Digital Forensics
- Threat Hunting
- Vulnerability Management

Completing these six courses gives you the Blue Team Junior Analyst Pathway Certificate.

**Get Started** 
You can register here https://www.centri.org/ to learn more about the courses.
