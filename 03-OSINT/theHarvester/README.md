theHarvester is a popular Python-based Open-Source Intelligence (OSINT) tool used by penetration testers, ethical hackers, and SOC analysts during the initial reconnaissance phase of a security assessment.

Its primary purpose is to perform passive footprinting—collecting publicly exposed assets belonging to an organization without directly interacting with or alerting the target's internal infrastructure.

# Example

- We run on kali linux cli the command: **theHarvester -d google.com -l 100 -b duckduckgo**.
- We use the tool, target domain = google.com , list 100 results max , source=duckduckgo.
