# Intro to Network Analysis Course 

Through this course, I learned how to use wireshark and tcpdump to capture network traffic, analyze packet captures and conduct security investigations.

# Overview
- Objectives: learn to use wireshark and tcpdump for network analysis.
- Analyze packets captures to understand network traffic. 
- Conduct security investigations using PCAP files.

# Practical Challenges

- Analyze 2 pcaps files using wireshark
- Analyze 2 pcasp files using tcpdump
- Malicious pcap investigation with malicious network traffic

# Tools Used

- Wireshark (Windows)
- TCPDump (Linux)
