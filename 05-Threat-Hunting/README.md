# Introduction to Threat Hunting 


Threat hunting is the proactive process of searching through networks and logs to detect and isolate advanced threats that bypass standard automated security tools.

# Objectives 

- Fundamentals of threat hunting
- How to generate indicator of compromise (IOCs) using tools
- Malware hunting


# Tools 
- VMs
- MD5, SHA1 Hashing
- Mandiant Redline
- Mandiant IOC Collector
